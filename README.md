# LAI — 本地 AI 助手

> 跑在 Android 手机上的离线大模型应用：模型下载、本地推理、对话交互，一部手机就是一个私有 AI 终端。

![version](https://img.shields.io/badge/version-1.1.1-4FC3F7) ![platform](https://img.shields.io/badge/platform-Android%208.0%2B-green) ![offline](https://img.shields.io/badge/offline-%E6%9C%AC%E5%9C%B0%E6%8E%A8%E7%90%86-orange)

## ✨ 功能特性

- **端侧离线推理** — 内置 llama.cpp 推理引擎，模型加载后全程本地运行，断网可用，对话数据不出设备
- **零配置开箱即用** — APK 内置 20 款模型目录（ModelScope 国内直链 + SHA256），无需自建服务器、无需填任何地址
- **全自动安装** — 首启自动硬件体检 → 自动选定最合适模型（中文优先）→ 确认后自动下载 → 自动加载启用 → 直达对话
- **后台下载保活** — 下载任务应用级持久化：切后台、息屏、进程被系统回收都不会丢进度；重新打开自动从断点续传，网络抖动自动退避重试，真断网则挂起、联网后自动继续
- **导入自己的模型** — 扫描本机目录或系统文件选择器导入任意 `.gguf`，自动解析元数据识别名称 / 架构 / 上下文 / 量化 / 参数规模，分片自动归组
- **硬件体检** — 自动识别 SoC / 内存 / 存储并评分，给出 L1~L4 适配档位与个性化模型推荐
- **模型库** — 20 款主流 GGUF 量化模型（Qwen2.5 / Llama3 / Gemma2 / DeepSeek-R1 / Phi3.5 等，0.36B~14B）
- **流式对话** — 聊天气泡逐 token 流式输出，实时显示生成速度（tokens/s），四套对话模板自动适配（ChatML / Llama3 / Gemma2 / Phi3）
- **OpenAI 兼容 API 服务** — 一键开启本地 API 服务器（`/v1/chat/completions`，支持 SSE 流式），自定义 API KEY，任何支持 OpenAI 协议接入的软件都能调用你手机上的模型

## 📥 下载安装

1. 进入 [Releases](../../releases) 页面
2. 下载最新版 `LAI-v1.1.1-release.apk`
3. 手机上允许"安装未知来源应用"后完成安装

**系统要求**：Android 8.0+（arm64 真机 / x86_64 模拟器）

> ⚠️ **从 v1.1.0 及更早版本升级**：v1.1.1 起改用**正式发布密钥**签名（此前 v1.0.0 / v1.1.0 均为 debug 调试签名）。两者签名不同，**无法覆盖安装**——请先卸载旧版再安装新版。卸载会清除已下载的模型与设置，需要重新下载模型（约 0.3~2GB）。此后发布的版本可正常覆盖升级。

## 🚀 快速上手

1. 启动 App，首页自动完成硬件体检并推荐适配模型
2. 点「同意并全自动安装」→ 自动下载（支持断点续传）→ SHA256 校验 → 加载 → 直达对话
   - 也可以进「模型库」手动挑选 20 款中的任意一款
   - 想用自己的模型？「模型库 → 导入模型」有两条路径：
     - **扫描本机模型**：自动在 Download / Documents / Models 等常见目录（含子目录）递归查找 `.gguf`
     - **从文件中选择**：走系统文件选择器，手动定位任意位置的 `.gguf`（可多选）
3. 「API 服务」页开启服务后：
   - 接口类型：OpenAI 兼容
   - Base URL：`http://127.0.0.1:8080/v1`（同机软件）或 `http://<手机IP>:8080/v1`（局域网设备）
   - API KEY：App 内自定义
   - 模型名：任意（自动路由到当前已加载模型）

## 🔒 隐私与安全

- 对话与推理全部本地完成，无任何遥测 / 云端上报
- API 服务强制 KEY 鉴权（恒时比较防时序侧信道），端口与 KEY 均可自定义
- 请求体大小限制 2MB，异常请求自动拒绝
